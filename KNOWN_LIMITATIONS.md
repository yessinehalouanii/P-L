# Prototype limitations

- The included Harbour Crest Resort dataset is synthetic.
- This demo uses CSV/XLSX upload and manual entry; it does not claim live vendor integrations.
- STR/CoStar data should come from authorized client reports/access, not uncontrolled scraping.
- Recommendations are rule-based decision support in this prototype and require consultant approval.
- Authentication, tenant isolation, audit logs, production file scanning, role-based permissions and enterprise deployment hardening are not implemented in this meeting prototype.
